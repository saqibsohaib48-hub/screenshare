        All reachable nodes

        NodeScope crawls the Bitcoin peer-to-peer network from DNS seeds, performs a version handshake with every node it can reach, and asks each one for more peers with getaddr. A node counts as reachable if it accepted an inbound connection during the crawl. Tor-only nodes are not counted, so totals are lower than estimates that include them.
